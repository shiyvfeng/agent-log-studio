# 猫咪 VLA：萝卜？纸巾？真棒！

这个整活示例把“大开门”听口令、伸爪辨识萝卜与纸巾的连续画面，编排成一本正经胡说八道的 VLA 运行日志。VLA 指 Vision–Language–Action（视觉、语言、行动）。前爪是执行器，选错是缓存污染，吃零食是胃部反向传播；技术术语与真实动作形成笑点。

## 成片

- 文件：`output/examples/cat-vla/cat-vla.mp4`。
- 规格：45.6 秒、1920 × 1080、30 fps、H.264 / AAC。
- 左侧：完整比例的竖屏原视频。
- 右侧：本项目 `/api/exports` 接口生成的中文日志动画，使用共享 Canvas 渲染器。
- 界面：Geist 风格的白底、黑灰排版与细边框；当前口令显示在顶部，阶段说明位于底部。
- 音频：直接保留原视频 AAC 音轨中的人类口令与反馈，不添加提示音或重新配音。

成片保留原文件的 0–45.6 秒，按原来的顺序与速度播放，剪去结尾的平台推广卡。画面包含口令重复、触碰物品、物体移位、目标切换、先伸向另一物品再改碰目标，以及“真棒”和投喂反馈。

## 界面设计

设计参考 [Vercel Geist 品牌规范](https://vercel.com/geist/brands) 及其官方字体说明。界面只保留视频、日志、当前口令和阶段说明四个层级，使用纯白背景、黑灰文字、1 像素边框、清晰对齐和留白。

视频区域为 432 × 768，日志区域为 1152 × 768，两者保持独立比例。日志使用中性配色，合成时消除残余色彩；动态文案沿用原时间线。界面英文排版使用官方 Geist Sans / Geist Mono，中文回退至 Noto Sans CJK。字体与官方 OFL 许可位于 `public/fonts/geist/`，来源版本记录在该目录的 README 中。

## 对齐依据

以下时间均从原视频第一帧起算，也是成片时间。动作时间为人工查看连续帧后的近似标记；口令和反馈按原视频内嵌字幕对齐。

| 时间 | 画面 / 原字幕 | 日志对应 |
| --- | --- | --- |
| 0–4.6 秒 | “萝卜”，猫先碰纸巾；口令重复后碰萝卜 | 指令、候选物体、初始选择、纠正、反馈 |
| 8.2–14.0 秒 | 两次“纸巾”，随后伸爪碰纸巾 | 等待、重新定位、动作、反馈 |
| 17.2–19.6 秒 | “萝卜”，猫向萝卜伸爪 | 语言目标与动作对应 |
| 22.0–27.0 秒 | 人手移动萝卜；猫伸爪；“纸巾”后转向纸巾 | 位置更新、目标切换、反馈 |
| 30.4–36.8 秒 | 两轮“萝卜”；萝卜朝向改变 | 同一物体的位置 / 朝向变化 |
| 41.2–45.0 秒 | “纸巾”，猫先伸向萝卜，再改碰纸巾，收到“真棒” | 犹豫、初始动作、纠正、奖励反馈 |

日志与阶段文案统一采用技术系统的口吻，例如「回滚纸巾分支」「奖励梯度进入胃部」「横着竖着都能换粮」「前爪提交热修复」。中英文版本均使用相同的整活语气。

## 复现

安装依赖，确认 Chrome / Chromium、系统 FFmpeg、ffprobe、curl 和中文字体可用，启动服务：

```sh
npm ci
npm run dev
```

另一个终端运行：

```sh
node scripts/make-cat-vla.mjs
```

脚本校验素材摘要与音轨，读取 `public/samples/cat-vla.csv`，请求项目导出接口生成日志层，再合成最终视频。产物包括素材、CSV 副本、设置、日志层、成片、封面和验证记录。

使用其他端口时设置 `AGENT_LOG_STUDIO_TEST_URL`。通过 `CHROME_PATH` 指定浏览器，`CAT_VLA_FONT` 指定中文字体文件，`CAT_VLA_FFMPEG` 指定 FFmpeg。默认中文字体为 `/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc`。

只调整合成版式或阶段字幕时，可复用已验证的日志层：

```sh
node scripts/make-cat-vla.mjs --compose-only
```

如果 CSV、渲染设置、帧率或时长变化，脚本会拒绝复用旧日志层，要求重新导出。

## 在编辑器中使用

示例菜单为「猫咪 VLA · 萝卜？纸巾？真棒！」。CSV 包含 44 条双语整活日志、`instruction` / `feed` / `think` / `action` 四种事件，以及可供对照素材的 `shot` 标记。可以改写段子或时间，在原有预览、播放和导出流程中继续编辑。`instruction` 文案用 `target=萝卜` 或 `target=纸巾` 声明目标，供顶部口令标记读取。
