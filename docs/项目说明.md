# 项目说明

日期：2026-10-10。

Agent Log Studio 是本机运行的通用 Agent 日志编辑与视频导出工具。

## 当前功能

- CSV 解析、导入／下载、时间轴、双层日志、类型配色与多场景编辑。
- Canvas 排版、播放／暂停、字幕式滚动、发光、折叠、Logo 与双语。
- 本地视频导出服务，包含 MP4、透明 WebM 和透明 MOV 编码路径。
- 网页上传原视频，设置裁切、日志延迟、原声、标题、署名与阶段字幕，同步预览并导出完整 MP4。
- 一键载入猫咪 VLA 的素材、日志与时间线；命令行示例与网页使用同一套合成接口。
- Vite 构建配置、依赖锁文件、模型测试和播放检查。

## 默认配置

- 应用名为 Agent Log Studio，包名和下载文件名前缀为 `agent-log-studio`，默认字符图案为 Agent Log Studio。
- 默认 HTTP 端口为 4320，开发热更新端口为 4321；草稿键为 `agent-log-studio-v1`。
- 内置示例包括研究助手、工作流助手、基础模板和猫咪 VLA 整活日志。
- CSV 支持双层日志和可选的类型字段。
- 测试使用通用样例，支持通过环境变量指定服务与 Chrome 路径。

源码仓库包含通用代码、示例日志、文档、测试、字体及其许可，以及 README 展示用的截图与短动图。用户日志、项目资料、原视频及完整生成产物放在忽略的 `output/` 目录；网页素材保存在 `output/media/`。

实时日志采集、Agent SDK 对接等功能尚未实现。
