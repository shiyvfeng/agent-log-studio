本目录保留用于示例视频界面的 Geist Regular、Geist SemiBold、Geist Mono Regular，原文件未修改。随附 `OFL.txt` 为官方 SIL Open Font License 1.1。

上游路径分别为 `fonts/Geist/ttf/Geist-Regular.ttf`、`fonts/Geist/ttf/Geist-SemiBold.ttf`、`fonts/GeistMono/ttf/GeistMono-Regular.ttf`。
